# the hearth pack

optional client mods, shaders and resource packs for the hearth, our survival
server on minecraft 26.2 (fabric). nothing in it is required to play: the
server runs a vanilla-client rule and always will.

server address: `vanilla.cinderworks.dev`

## install

1. get the newest `.mrpack` from [modrinth](https://modrinth.com/modpack/the-hearth-pack), [releases](https://github.com/cinderworks-mc/the-hearth-pack/releases) or the [pack page](https://cinderworks.dev/hearth/pack/)
2. in the [modrinth app](https://modrinth.com/app): add instance, then from file, then pick the `.mrpack`
3. join `vanilla.cinderworks.dev` (it is already in your server list)

prism launcher and atlauncher import `.mrpack` files too.

## what is in here

`build_mrpack.py` holds the full list (81 mods, 3 shaderpacks, 9 resource
packs), `overrides/` carries our defaults. nothing third party is bundled:
every file comes from its author's own modrinth upload.

more at [cinderworks.dev](https://cinderworks.dev)
